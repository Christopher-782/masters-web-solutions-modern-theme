# MASTER'S WEB SOLUTIONS

Complete Next.js website restored to the clean sage/cream design state from immediately before the site-wide animated motion background changes.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Included

- Floating responsive navigation
- Sage/cream brand theme and matching logo
- Business automation hero with live HTML/CSS dashboard
- Business value strip
- Four solution areas, including Custom Websites
- Transformation showcase using the supplied manual-to-automated visual
- Systems showcase
- Process timeline
- Improved consultation CTA
- Clearer explanatory copy and hover/focus detail interactions
- Responsive/mobile styling
- Accessibility and reduced-motion support

This build intentionally excludes the later site-wide ambient/motion-background experiment and the subsequent hero spacing/visibility patches made only to troubleshoot it.
